# Command Reference

Macro Studio discovers commands from Python command modules. The built-in library is grouped as follows:

| Category | Typical capabilities |
| --- | --- |
| Audio | Play audio, stop audio, wait for audio |
| Clipboard | Read, write, clear, and paste clipboard data |
| Dialogs | Messages, confirmations, text/number/password input, file/folder pickers |
| Files | Copy, read, write, search, and edit files |
| Flow control | Loops, conditions, jumps, nested macro groups, stop commands |
| Keyboard | Key presses, hotkeys, text entry, global hotkey registration |
| Mouse | Move, click, and scroll |
| Numbers | Calculate, change, and round numeric values |
| Screen recognition | Captured-image and pixel-color waits and searches |
| System | Open URLs, run commands, run Python |
| Text | Format, append, replace, extract, split, join, reverse, and measure text |
| Timing | Waits, indefinite waits, timers |
| Variables | Set/check variables and generate random values |
| Windows | Find, close, move, resize, change opacity, and change window state |

Command availability can depend on the operating system and optional Python packages. If a command does not appear, inspect the eDock console for the module import error and verify its dependency.
